What these labels mean.

Publicly open: a landing page was accessible when checked. Sign-in: the current address requires authentication. Historical: the former link was not serving its intended page. Development: only a code or editor project was confirmed; no public deployment. None of these labels proves app functions, health claims or account data are correct.

The directory links related projects but does not copy, merge or synchronise health records between them. Favourites save only project IDs in this browser. External destinations can have their own privacy policies, account requirements and storage.
