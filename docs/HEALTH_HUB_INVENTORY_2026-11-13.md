# Josh’s health website inventory — 13 November 2026

## Purpose

A single linkable directory for personal health data apps, heart and calming tools, exercise/physiotherapy, food and longevity, health reference, broad wellbeing, and prior experiments. The public interactive index is **https://healthiest-food.vercel.app/health-hub.html**.

**Data source:** the checked catalogue is maintained in [`health-hub-data.js`](../health-hub-data.js). This document is an audit snapshot, not a live uptime monitor. A successful landing page does **not** prove authentication, data ingestion, remote APIs, correctness, medical safety or data sync.

## Discovery and verification

- Searched the four linked GitHub identities, including the `joshualparris` and `Parris-Tech-Services` repository inventories, source READMEs and the pre-existing HealthiestFood related-sites inventory (17 Oct).
- Inspected connected Vercel team project inventory (84 projects), project domains and selected deployment states.
- Checked accessible Cloudflare Workers and Replit projects and current Replit publish statuses.
- Probed the named live website addresses using public, unauthenticated page loads on 13 Nov 2026.
- Grouped sites which display the same analyser (e.g., misleading 'physio' aliases) or same relationship product (HugCoach/JoshCoach). Kept historic 404s and unpublished Replit projects visible but plainly labelled.

## Coverage

- 22 indexed cards across 7 categories, with 33 individual URL destinations.
- 10 publicly open primary pages, 6 requiring sign-in, 2 historical addresses, and 4 source-only/unpublished projects.
- Unknown or unconnected historical accounts, removed sites and domains could still exist; **no claim that every possible deleted or unconnected project has been found**.

## Known limitations and safety

- HealthiestPeople and Sleepy’s old Pages URLs are presently unavailable. The HealthiestPeople GitHub repository is private; 'live site' claims in its older README do not supersede current testing.
- Main HealthLens, Health Reference, JoshHub, LifeHub, HugCoach and Ignite Us endpoints required login from public tests.
- The older JoshHealthHub loads but shows an empty dataset; a reachable front-end is not evidence that its data import or account state is functional.
- Gentle Motion Physio and Physio Companion deployments display a Josh Health Analyser edition; do not confuse them with the independently available Gentle Movement or PhysioBuddy exercise products.
- Source-only Replit projects were confirmed unpublished. No source-only project is represented as a working live site.
- This public index contains *links and project descriptions only*, not raw personal clinical exports, dates of medical procedures, tokens, passwords or records. Whether data is shared across each destination must be assessed separately.
- To update statuses and URLs, edit `health-hub-data.js`, rerun `node --test tests/health-hub.test.cjs` and the Chromium/Firefox/WebKit tests in `e2e/health-hub.cjs`, then verify the production address.
